# 📱 Activity 3 — Social Media Infographics and Mini Project Documentation

## 📌 Overview

This activity focused on creating social media infographics and
documenting the creative process behind the mini project.

The activity combined visual communication, information organization,
graphic design, and digital storytelling.

---

## 💡 Concept

The concept was developed around presenting information in a format
that is easy to understand and suitable for social media.

Because audiences often encounter content quickly while scrolling,
the infographic needed to communicate its main message clearly and
efficiently.

---

## 🎯 Target Audience

The design was developed with the intended audience in mind by
considering readability, information density, visual appeal, and
ease of understanding.

---

## 🎨 Design Choices

### Visual Hierarchy

Important information was given greater visual emphasis through
size, placement, and contrast.

### Color

The established color palette was maintained to create visual
consistency.

### Typography

Different font sizes and weights were used to distinguish headings,
supporting information, and details.

### Layout

Information was divided into sections to prevent the infographic
from becoming visually overwhelming.

### Visual Elements

Graphics and other visual elements were used to support the message
rather than distract from it.

---

## 🛠️ Creative Process

**Research → Concept → Layout → Design → Revision → Final Output**

### 1. Research

Relevant information was gathered and reviewed.

### 2. Concept Development

The main message and visual direction were established.

### 3. Layout

Information was organized according to importance.

### 4. Design

Color, typography, graphics, and other visual elements were applied.

### 5. Revision

The design was reviewed for readability, balance, hierarchy, and
consistency.

### 6. Finalization

The revised infographic was prepared as the final output.

---

## 🔄 Revisions

The design was refined by adjusting the arrangement of information,
spacing, typography, and visual elements.

These revisions helped create a clearer and more balanced final output.
