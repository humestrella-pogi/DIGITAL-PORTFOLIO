# Activity 2 — Color Palette and Typography

## 📌 Overview

Activity 2 focused on selecting an appropriate color palette and
typography system for a visual project.

The objective was to create a consistent visual identity while ensuring
that the chosen colors and fonts remained readable and appropriate
for the intended audience.

## 💡 Concept

The concept was developed around creating a visual identity that was
simple, consistent, and recognizable.

Color and typography were treated as important communication tools
rather than merely decorative elements.

## 🎨 Color Palette

### Primary Color — #63483D

A warm brown tone was selected as the primary color. It provides a
grounded and professional visual character while giving the design
a distinctive identity.

### Secondary Color — #FFFFF5

An off-white tone was used as a background or supporting color. It
provides visual space and improves readability.

### Neutral Color — #000000

Black was used primarily for text and high-contrast elements. It
provides strong readability and helps important information remain clear.

## 🔤 Typography

The typography was selected based on:

- Readability
- Simplicity
- Professional appearance
- Clear hierarchy
- Compatibility with digital layouts

Different font sizes and weights were used to distinguish:

**Title → Heading → Subheading → Body Text**

## 🛠️ Development Process

1. Identified the intended mood and identity.
2. Selected a primary color.
3. Added supporting and neutral colors.
4. Tested color combinations.
5. Selected appropriate typefaces.
6. Established a hierarchy between headings and body text.
7. Tested readability.
8. Applied the system consistently across the design.

## 🎯 Why These Choices Were Made

The selected palette creates a simple and cohesive visual identity.
The typography complements the colors by maintaining readability and
creating clear distinctions between different levels of information.

Together, the colors and typography provide consistency across the
project's visual materials.
